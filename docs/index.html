Why bearcli

✨ Agent-ready

Ships an Agent Skill so Claude Code and other AI agents can drive your notes safely.

Fuzzy search

Typo-tolerant, ranked search across titles, tags, and note text - or plain case-insensitive matching by default.

Git backup & sync

--push mirrors your notes to a private repo: only changed notes rewritten, deletions cleaned up, every edit kept in history. Self-converging, never stuck.

Secret protection

Exports are scanned for credentials first - block, or --redact-secrets to replace them with placeholders. Fully offline.

Self-contained exports

Each note becomes a portable folder - README.md + attachments - plus a generated index. GitHub renders the whole tree.

Scriptable

Every listing has json and tab-separated text output, built for jq, cut, and pipes.

⚠️ A note on secrets. Detection and redaction are best-effort: they catch known token formats, credential assignments, and high-entropy strings, but a secret that reads like ordinary text - a password written as prose, an account number - will not be caught. Ideally, don't keep secrets in notes at all: use a password manager, or Bear's encrypted notes, which never leave the app.

✨ For AI agents

bearcli ships an Agent Skill that teaches Claude Code (and other skill-aware agents) how to drive the CLI - machine-readable output, id prefixes, write verification, and the redact-before-sharing rules. Your agent can answer “what did I write about X?” straight from your notes.

❯ cp -r skills/bear-notes ~/.claude/skills/

Commands

CommandWhat it does
bearcli note listList notes with tag, date, and status filters
bearcli note searchSearch titles, tags, and content - --fuzzy for typo tolerance
bearcli note getPrint a note's markdown, metadata, and attachment paths
bearcli note createCreate a note from arguments or stdin
bearcli note append / replace / renameEdit an existing note
bearcli note attachAdd a file to a note
bearcli note tag / untagAdd or remove a tag on one note
bearcli note trash / archive / openFile a note away, or open it in Bear
bearcli tag list / rename / deleteManage tags across all notes
bearcli exportExport everything as browsable markdown folders - secret-scanned, and --push mirrors to a git repo
